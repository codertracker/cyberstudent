StudioLav

Live

Gestionale di fatturazione full-stack sviluppato per lo Studio di Consulenza del Lavoro Rustignoli Cinzia. Il sistema automatizza l'emissione di fatture, la gestione clienti e il tracking dei pagamenti, sostituendo un flusso cartaceo con una soluzione digitale scalabile e sicura.

Dettagli tecnici

  • Frontend in HTML5 / CSS3 / JavaScript vanilla con UX ottimizzata per uso quotidiano
  • Backend Node.js con API REST per gestione dati e autenticazione
  • Database MariaDB con schema normalizzato per clienti, fatture e voci
  • Deploy su Vercel con variabili d'ambiente protette
  • Backup manuale dei dati (automazione pianificata con cron job + storage remoto)
  • Autenticazione con sessioni sicure e protezione CSRF
HTML5 CSS3 JavaScript Node.js MariaDB MySQL Vercel Python

Linux Cluster ElerNode — Homelab

In sviluppo

Progettazione e documentazione di un cluster Linux ad alte prestazioni completamente headless (senza GUI). Include configurazione avanzata di Rocky Linux, orchestrazione container con Docker e Podman, reverse proxy con Nginx Proxy Manager e strategie di Disaster Recovery documentate step-by-step.

Stack infrastrutturale

  • Rocky Linux 10 come OS base (RHEL-compatible, enterprise grade)
  • Proxmox VE per virtualizzazione e gestione LVM
  • Docker e Podman per containerizzazione dei servizi
  • Cloudflare Tunnel (Cloudflared) per esposizione sicura senza aprire porte
  • Nginx Proxy Manager per routing del traffico interno/esterno
  • Kubernetes (in fase di integrazione) per orchestrazione avanzata
  • Script Python/Bash per automazione backup e health-check
  • Documentazione tecnica completa con esempi pratici e troubleshooting
Rocky Linux Proxmox Docker Podman Kubernetes Nginx PM Cloudflare Bash Python
